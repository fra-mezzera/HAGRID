MODULE 02 FILE DESCRIPTION - CONVENTIONAL LOAD CONSUMPTION PROFILES EXCEL FILES



	In this folder, several .xlsx (Excel) files are generated, to provide different information about electricity consumption related to appliance and lighting usage by the households in the tested residential local energy system.
	The information are grouped as follows, distinguishing for the simulated Horizon period (i.e., the tested representative week, Summer, Winter etc):

	- load curves of conventional consumption --> to evaluate what are single household peaks derived by only the conventional consumptions

	- percentile distribution --> useful to evaluate electricity (conventional) consumption distribution

	- summary --> a summary of the electricity consumption behavior over the simulated period grouped by appliance type or household


Then, also 10-min resolution timeseries are generated:
	- aggregated household conventional consumption timeserie (differentiating between constant consumption derived by refrigerator, stand-by etc v. other appliances, like ironing, TV etc)

	- grouped for appliance class

	- the sum of all conventional electricity consupmtion of ALL households in one single timeserie (useful for aggregated check)

	- the conventional electricity consumption profile of EACH SINGLE individual member (divided and recognized in each single household)
