MODULE 03 FILE DESCRIPTION - ADDITIONAL LOAD CONSUMPTION EXCEL FILES


	In this folder several Excel (.xlsx) files are generated, differentiated by the type of tested residential local energy system (geographical area, grid archetype/system dimension/n° households)

A brief non Comprehensive description of the following files:


	- Cooling_consumption_kWh --> timeseries with individual space cooling consumption in all the tested households

	- DHW_consumption_kWh --> timeseries with individual domestic hot water consumption in all the tested households

	- DHW_overlap --> file to check how often there are simultaneous showers within the same household (ie between different members)


	- EV_electricity_demand_kWh --> timeseries with individual EV electricity demand in all the tested households

	-  EV_home_greedy_charging_kWh --> timeseries with individual home electricity consumption for charging EV in all the tested households

	-  EV_km_travelled --> timeseries with individual transport demand (in km) in all the tested households

	-  EV_metadata_by_person --> technical EV parameters assigned to each household (ie. EV type, specific consumption, battery capacity in kWh etc)

	-  EV_work_greedy_charging_kWh --> timeseries with individual work electricity consumption for charging EV in workplace in all the tested households

	- Heating_consumption_kWh --> timeseries with individual space heating consumption in all the tested households

	- Induction_consumption_kWh --> timeseries with individual cooking consumption in all the tested households

	- Occupancy --> timeseries with individual space occupancy in all the tested households (1=at home, 0=outdoor)

	- SoC_EV--> timeseries with state of charge of EV battery in all the tested households


	- timeseries_kWh_per_household_TOT --> timeseries with ALL ADDITIONAL electricity consupmtion (ONLY additional) in all the tested households

	- ts_kWh_el_by_household_by_load --> timeseries with each additional electricity load contribution in every household


	- weekly_aggregated_ts_kWh_additional_loads --> additional load value aggregated over the entire simulated Horizon (week)
