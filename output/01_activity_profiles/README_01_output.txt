MODULE 01 FILE DESCRIPTION - ACTIVITY PROFILES OF INDIVIDUAL CLASSES

In the current folder, two subfolders are included:

	- yearly_profiles --> in which the 10-min resolution yearly timeseries with individual activity profiles are included, differentiating by geographical area (e.g. Nord/North, Sud/South…) and individual member (i.e., head of household, spouse or child) and household type (e.g., single-person, couple with Children, couple without Children etc). For the classification of individuals, same categories provided in the Time-Use-Survey dataset by the Italian National Institute of Statistics (ISTAT) are adopted

	- weekly_profiles --> the same 10-min resolution profiles along four selected representative weeks (one per season), defined in the MODULE_01 code. Please, be aware that any change in the choice of the representative period would have to be considered in all the following modules, by adapting also the other input data/timeseries (e.g. the space heating/space cooling profiles, the PV generation profiles, the outdoor temperature etc)

	- an example of Weekly profile is included in the subfolder "weekly_profiles\Cen", for the household type (0,0 = single-person), while for the other individual classes they have to be calculated through MODULE 01. (due to space upload limits the remaining cases were cancelled in the current version and have to be reconstructed running Module 01)
