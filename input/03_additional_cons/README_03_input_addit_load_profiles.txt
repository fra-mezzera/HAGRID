MODULE 03 FILE DESCRIPTION - TIMESERIES TO RECONSTRUCT SPACE HEATING AND COOLING PROFILES


	In this folder the main input data required to build space cooling and space heating profiles are generated.

	- For space cooling, the obtained individual space cooling profiles (based on the methodology presented, that considers both occupancy individual profiles and environmental conditions, such as relative humidity and outdoor temperature) for a tested case study in Central Italy are presented

	- For space heating, the correlations to distribute heating demand across the day, the correlation between outdoor temperature and the coefficient of performance (COP) of an electric heat pump and the climate data for a case study in Central Italy are provided
